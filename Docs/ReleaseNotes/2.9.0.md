# TorrServe Silicon 2.9.0

## Русский

- Добавлена анонимная статистика использования: случайный ID установки, версии приложения и macOS, семейство процессора. Отправка — не чаще одного раза в 24 часа, без влияния на запуск приложения.
- Статистику можно отключить в настройках конфиденциальности. Названия торрентов, пути к файлам и история просмотров не передаются; IP и User-Agent не записываются в базу статистики. Страна определяется Cloudflare по подключению и может зависеть от VPN.
- Обновлены интерфейс медиатеки и меню в строке меню. Поиск настроек находит отдельные параметры и прокручивает к ним.

## English

- Added anonymous usage statistics: a random installation ID, app and macOS versions, and CPU family. Reports are sent at most once per 24 hours without blocking application launch.
- Usage statistics can be disabled in Privacy settings. Torrent names, file paths, and viewing history are not sent; IP addresses and User-Agent are not stored in the analytics database. Cloudflare derives the connection country, which may be affected by a VPN.
- Refined the library and menu bar interface. Settings search finds individual controls and scrolls to them.

## Requirements / Требования

macOS 15 or later, Apple Silicon. The application uses ad-hoc signing and is not notarized, consistent with previous releases.
