# Офлайн-медиатека

Раздел «Офлайн» показывает материалы, а не плоский список файлов. Поддерживаются
список с подробностями, постеры и большие карточки. Выбор вида хранится отдельно
от медиатеки в `OfflineLibraryDisplayMode`.

Новые задания и завершённые загрузки сохраняют необязательное поле `media`:
идентификатор материала, название, URL постера, признак сериала и хеш торрента.
Поле проходит через очередь и checkpoint до истории завершённых загрузок.
Схема контейнеров остаётся версии 1: старые записи без `media` читаются, а старые
версии приложения могут игнорировать добавленное поле. Файлы видео не перемещаются.

Группировка использует идентификатор провайдера и тип материала, если тип известен
и соответствует найденному контенту. Без этого используется хеш торрента. Старые
записи дополняются сохранёнными метаданными медиатеки и сведениями из новых загрузок
того же торрента. Одинаковое название файла само по себе не объединяет разные торренты.
Разные сезоны в отдельных раздачах объединяются при наличии общего идентификатора
сериала в метаданных; без него карточки разных торрентов остаются отдельными.

Внутри материала доступны только реально скачанные файлы. Серии группируются по
сезону для имён S01E01 и 1x01; остальные имена отображаются в разделе «Файлы».
Порядок файлов учитывает числа. Удаление одного файла не удаляет остальные серии.
Карточка исчезает после удаления последнего файла.

Демо-заполнение создаёт 15 материалов: 12 фильмов и 3 сериала с четырьмя сериями
в двух сезонах каждый. Все записи остаются в памяти; реальные файлы и история
загрузок не меняются.
