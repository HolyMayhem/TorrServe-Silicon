# TorrServer для macOS

[English](README.md) | **Русский**

Нативное SwiftUI-приложение для управления TorrServer на Mac с Apple Silicon.
Оно объединяет управление сервером, поиск раздач, медиатеку, метаданные,
воспроизведение и menu bar — для повседневного использования не нужны Терминал
и стандартный Web UI TorrServer.

Интерфейс следует современным принципам macOS и использует нативный Liquid Glass
в macOS 26. На более ранних поддерживаемых версиях применяются совместимые
системные материалы.

## Основные возможности

- Запуск, остановка, обновление, настройка и диагностика TorrServer.
- Добавление magnet-ссылок и `.torrent`-файлов прямо в библиотеку.
- Три вида библиотеки: компактный список, сетка постеров и подробные карточки.
- Поиск раздач через необязательное подключение к Jackett.
- Загрузка постеров, описаний, жанров, дат выхода, продолжительности и рейтингов
  из TMDB, OMDb, КиноПоиска и AniList.
- Настраиваемый порядок поиска метаданных и встроенные либо собственные API-ключи.
- Перевод английских описаний на русский средствами Apple Translation.
- Воспроизведение в QuickTime Player, IINA, VLC, Infuse или системном приложении.
- Управление из menu bar: текущая скорость стрима, недавний материал, быстрые
  действия и QR-код локального Web UI.
- Изменение порядка секций menu bar перетаскиванием мышью.
- Полный интерфейс на русском и английском языках.

## Управление сервером

Исполняемый файл `TorrServer-darwin-arm64` для Apple Silicon добавляется внутрь
приложения при упаковке. В разделе «Настройки сервера» доступны:

- изменение пути к исполняемому файлу и хранилищу;
- настройка кэша в памяти и на диске;
- проверка и установка обновлений TorrServer;
- информация о хранилище и очистка кэша;
- диагностика исполняемого файла, порта, API, Web UI, хранилища и плееров.

При необходимости Web UI по-прежнему можно открыть непосредственно из
приложения.

## Установка

1. Скачайте актуальный `TorrServer-*-macOS-arm64.dmg` в разделе
   [Releases](https://github.com/HolyMayhem/TorrServe-Silicon/releases).
2. Откройте DMG.
3. Перетащите `TorrServer.app` в папку `Applications`.
4. Запустите приложение и выберите предпочитаемый плеер.

Если macOS блокирует первый запуск ненотаризованной сборки, нажмите на
приложение с зажатой клавишей Control и выберите **Открыть** либо разрешите
запуск в разделе **Системные настройки → Конфиденциальность и безопасность**.

## Необязательные интеграции

### Jackett

[Jackett](https://github.com/Jackett/Jackett) нужен только для раздела «Поиск».
Его адрес и API-ключ задаются в общих настройках. Библиотека, управление
сервером и воспроизведение работают без Jackett.

### Источники метаданных

Метаданные необязательны. В общих настройках можно выбрать источник и
использовать встроенные либо собственные API-ключи. Поддерживаются TMDB, OMDb,
КиноПоиск и AniList для распознавания аниме.

### Внешние плееры

QuickTime Player доступен в macOS по умолчанию. IINA, VLC и Infuse необходимо
установить отдельно, прежде чем выбирать их в приложении.

## Системные требования

- macOS 15 или новее.
- Mac с Apple Silicon.
- Доступ к сети для TorrServer и включённых сервисов поиска или метаданных.

## Сборка из исходников

Для создания готового приложения требуется актуальная версия Xcode с поддержкой
Icon Composer.

```bash
git clone https://github.com/HolyMayhem/TorrServe-Silicon.git
cd TorrServe-Silicon
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build-app.sh
```

Готовое приложение появится в `build/app/TorrServer.app`. Если переменная
`TORRSERVER_EXECUTABLE` не указывает на локальный arm64-файл, скрипт скачает
актуальную версию исполняемого файла из исходного проекта
[TorrServer](https://github.com/YouROK/TorrServer).

## Создание DMG

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/package-dmg.sh
```

Готовый образ появится в `dist/TorrServer-<версия>-macOS-arm64.dmg`. Локальная
сборка использует ad-hoc подпись и не проходит нотаризацию Apple.

## Структура проекта

- `Sources/App` — жизненный цикл приложения, окно, сайдбар и общее состояние.
- `Sources/Core` — API TorrServer, форматирование, UI- и системные компоненты.
- `Sources/Features` — библиотека, поиск, метаданные, сервер, настройки и menu bar.
- `Tests/TorrServerManagerTests` — тесты сервисов, моделей, форматирования и настроек.
- `scripts` — сборка приложения, компиляция иконки и упаковка DMG.
