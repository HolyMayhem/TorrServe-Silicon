# TorrServe Silicon

English | **Русский**

**Нативное приложение TorrServer для macOS.**

TorrServe Silicon объединяет TorrServer, медиатеку, поиск торрентов, метаданные и запуск воспроизведения в одном приложении.

Добавьте торрент → приложение определит фильм или сериал → загрузит постер, описание и рейтинги → нажмите **«Смотреть»**.

Без постоянной работы с Терминалом и Web UI TorrServer.

---

## Возможности

- запуск и управление **TorrServer** прямо из приложения;
- добавление **magnet-ссылок** и **`.torrent`-файлов**;
- медиатека с постерами вместо обычного списка торрентов;
- автоматическое определение фильмов, сериалов и аниме;
- загрузка описаний, жанров, года, рейтингов и других метаданных;
- поиск раздач через **Jackett**;
- запуск просмотра в **QuickTime, IINA, VLC или Infuse**;
- управление TorrServer из **menu bar macOS**;
- русский и английский интерфейс.

---

## Умные метаданные

TorrServe Silicon анализирует название торрента и пытается автоматически определить его содержимое.

Например:

`Interstellar.2014.2160p.UHD.BluRay.REMUX`

превращается в полноценную карточку фильма с постером, названием, описанием, жанрами и рейтингом.

Для поиска используются:

**TMDB · OMDb · КиноПоиск · AniList**

Если один источник не нашёл информацию, приложение может попробовать следующий.

Для аниме поддерживается **AniList**.

Английские описания при необходимости могут переводиться на русский через системный **Apple Translation**.

---

## Поиск через Jackett

Если у вас настроен [Jackett](https://github.com/Jackett/Jackett), раздачи можно искать прямо внутри приложения:

**нашли фильм → выбрали торрент → добавили → начали просмотр.**

Jackett необязателен — без него медиатека, TorrServer и метаданные продолжат работать.

## Установка

1. Откройте [Releases](https://github.com/HolyMayhem/TorrServe-Silicon/releases).
2. Скачайте последнюю версию `TorrServer-*-macOS-arm64.dmg`.
3. Откройте DMG.
4. Перетащите TorrServe Silicon в **Applications**.
5. Запустите приложение.

**TorrServer уже включён в приложение и отдельно устанавливать его не нужно.**

> [!NOTE]
> Если macOS блокирует первый запуск, откройте
> **Системные настройки → Конфиденциальность и безопасность**
> и разрешите запуск приложения.

---

## Системные требования

- **macOS 15 или новее**
- **Mac с Apple Silicon**
- интернет-соединение

На macOS 26 приложение использует нативный **Liquid Glass**.
